CSS Positioning

Five values, one element at a time. Inspect each box as you go.

1. static — the default

position: static
top: 40px is set but ignored

A static element ignores top, right, bottom, left and z-index completely. This is why your first attempt at nudging something usually does nothing.

2. relative — nudged, but its space is kept

before
position: relative
top: 20px · left: 30px
after

The box moved, but the gap where it used to be is still there. Nothing else on the page shifted. That is the difference between relative and absolute.

3. absolute — removed from the flow

With a positioned parent (correct)

stage has position: relative
position: absolute
top: 12px · right: 12px

With NO positioned parent (the classic bug)

stage has position: static
absolute, no positioned parent
it measures from the page

Scroll to the very top of this page to find the second box. It jumped to the document corner because no ancestor was positioned.

4. fixed — pinned to the viewport

The dark circle at the bottom right of your screen is position: fixed. Scroll: it does not move. It was removed from the flow, so no space is reserved for it anywhere.

7. z-index and stacking

z-index: 1
z-index: 3
z-index: 2

Inspect each one. Now try this in DevTools: remove position: absolute from the middle box. Its z-index stops working immediately, because z-index needs a positioned element.

The trap: a trapped child

parent has z-index: 1
child has z-index: 9999 and still loses
sibling has z-index: 2 and wins

A child can never rise above its parent's level. This is why 9999 sometimes does nothing at all.
