# Class 1 — Web Architecture

Concept class. No code files.

**Topics:** client/server model, DNS lookup, HTTP request and response, status
codes, how a browser renders a page, and what hosting means.

**Try this yourself:**

1. Open any website, press `F12`, and choose the **Network** tab.
2. Reload the page.
3. Look at the first request. What status code came back? How large was it?
   How long did it take?
4. Find one request with status `304` and one with `200`. What is the
   difference?

**Status codes worth remembering:** `200` OK · `301` moved permanently ·
`304` not modified · `403` forbidden · `404` not found · `500` server error.
