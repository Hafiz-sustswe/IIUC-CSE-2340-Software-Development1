# Class 4 — Git Basics

Practice class. The "code" for this class is a set of commands, not a program.

## Files here

- `README-template.md` — a starting point for your own project README.
  Copy it into your project, rename it to `README.md`, and fill it in.
- `gitignore-example.txt` — a sensible ignore list for a web project.
  Copy it into your project and rename it to `.gitignore` (with the dot,
  and no `.txt`).

## The full command reference

See [`../../study-materials/handouts/git-cheatsheet.md`](../../study-materials/handouts/git-cheatsheet.md).

## The loop you will run all semester

```bash
git status
git add .
git commit -m "Describe what changed"
git push
```
