# Class 2 — Development Environment

Practice class. You build your first HTML file here.

**Setup checklist:**

- [ ] VS Code installed
- [ ] Live Server extension installed (by Ritwick Dey)
- [ ] Node.js installed — check with `node -v` and `npm -v`
- [ ] A folder created for this course, outside Downloads

**Your first file:**

1. Create a folder named `first-page`.
2. Create a file inside it named `index.html`.
3. Type `!` and press `Tab`. VS Code writes the whole HTML skeleton for you.
4. Change the `<title>` and add an `<h1>` inside `<body>`.
5. Save with `Ctrl + S`, right click the file, choose **Open with Live Server**.

**If the page does not update:** you did not save, or Live Server is showing a
different file. Check the URL in the browser.
