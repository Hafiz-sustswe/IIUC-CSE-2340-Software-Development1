# Assessment Overview — CSE-2340, Autumn 2026

The short version. Full details are in the syllabus PDF in this folder.

## Marks

| Component | Marks | Nature |
|---|---|---|
| Attendance | 10 | Continuous |
| Mid-term in-lab practical | 20 | Individual, 100 minutes, Week 7 C3–C4 |
| Six mini projects | 40 | Individual, each with a dedicated evaluation class |
| Final group project and showcase | 30 | Team project plus individual viva |
| **Total** | **100** | |

## Mini projects

| Project | Due | Deliverable | Marks |
|---|---|---|---|
| MP1 | Week 3, C4 | Semantic HTML + CSS + responsive layout + deployment | 5 |
| MP2 | Week 5, C4 | Own responsive design with Tailwind + deployment | 5 |
| MP3 | Week 8, C4 | DOM manipulation application or debugging task | 7 |
| MP4 | Week 10, C4 | API application + localStorage + loading/error states | 7 |
| MP5 | Week 13, C4 | React SPA + routing + reusable components + ShadCN/ui | 8 |

## Mini project rubric

| Criterion | Weight | What is checked |
|---|---|---|
| Core functionality | 40% | The required feature works correctly |
| Technical implementation | 25% | Appropriate technique is used |
| Responsiveness and usability | 15% | Behaves correctly on different screen sizes |
| Code organisation | 10% | Reasonable structure, naming and readability |
| Individual demonstration | 10% | You can explain, modify or debug your own work |

## How a mini project is evaluated

1. Repository link and deployed URL are submitted **before** the evaluation class.
2. Students are called in a fixed order.
3. Each student gives a short live demonstration of the required feature.
4. The instructor asks one or two ownership or debugging questions.
5. If time allows, the student makes one small modification live.
6. The rubric is recorded immediately.

## Mid-term practical — Week 7, C3–C4

- 100 minutes, 20 marks, individual
- Semantic HTML, responsive CSS, and at least one meaningful JavaScript interaction
- No React and no Firebase — nothing scheduled after the mid-term
- Emphasis on implementation, responsiveness, interaction and debugging, not memorisation
- Replaces the regular Week 7 C3 and C4 classes

## Final group project

Teams of three, formed in Week 8.

- At least three routes
- Authentication with protected routes
- One Firestore collection with basic read and write
- At least one meaningful ShadCN/ui feature
- Responsive design and deployment
- A README with setup and feature information
- Each member owns at least one feature end to end
- Each member works on an individual branch and opens a pull request
- Each member makes at least eight meaningful commits
- Each member completes an individual viva

## AI tools

You may use AI tools openly. Project evaluation requires repository evidence and
a short live demonstration or modification to verify ownership and understanding.
