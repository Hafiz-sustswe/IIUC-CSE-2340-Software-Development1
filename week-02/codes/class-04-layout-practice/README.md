# Class 4 — Layout Practice and Debugging

Practice class. You spend most of it in DevTools, not in slides.

## Files

```
class-04-layout-practice/
├── exercises.md      the four exercises, with the debugging method
├── starter/          BROKEN ON PURPOSE — eight bugs in styles.css
│   ├── index.html    correct HTML. Do not change it
│   ├── styles.css    all eight bugs live here
│   └── images/       put campus.jpg here
└── solution/         all eight fixed, each marked FIX n
    ├── index.html
    ├── styles.css
    └── images/
```

## Start here

1. Open `starter/index.html` with Live Server.
2. Read `exercises.md`.
3. Work through Exercise 1 before opening anything in `solution/`.

## Compare starter and solution

In VS Code, select `starter/styles.css` and `solution/styles.css` in the
explorer, right click, and choose **Compare Selected**. Only eight things
differ, and each one is commented.

## The one rule

Do not edit `starter/index.html`. The HTML is already correct. Every problem in
this exercise is a CSS problem, which is the point: good structure lets you fix
appearance without touching the markup.
