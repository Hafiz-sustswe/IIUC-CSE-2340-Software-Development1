# Class 1 — Navigation, Forms and Tables

## Files

- `register.html` — the complete student registration page built in class.
  Contains all three patterns: a nav, a two-fieldset form, and a data table.
- `snippets.html` — one demonstration per element, used during the slides.

## Deliberate bugs in snippets.html

These are teaching demonstrations. Do not fix them.

1. A menu built from `<span>` tags — try pressing `Tab`, you cannot reach it.
2. Two radio buttons with different `name` values — both can be selected.
3. A `<label for="wrong-name">` that matches no `id` — clicking it does nothing.

## Run it

Open the folder in VS Code, right click `register.html`, choose
**Open with Live Server**.

No CSS yet. The plain appearance is intentional.
