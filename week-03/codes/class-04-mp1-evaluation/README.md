# Class 4 — Mini Project 1 Evaluation

Not a teaching class. This is a dedicated 50-minute evaluation session: each
student demonstrates their deployed project, answers one or two ownership
questions, and makes a small live modification.

## For students

Everything you need is in the brief:
[`../../study-materials/handouts/mp1-brief.md`](../../study-materials/handouts/mp1-brief.md)

**Submit before the class**, not during it:

1. Your GitHub repository URL
2. Your deployed URL

Then, while you wait:

- Open your deployed URL and check it loads
- Open your repository in another tab
- Press `F12`, then `Ctrl+Shift+M`, and set the width to 360px
- Re-read your own CSS for two minutes

Do **not** push new commits during the evaluation, and do not switch to a local
copy because the live one is broken. If your deployment is broken, say so at the
start of the class — you get the remaining time to fix it and are evaluated last.

## For the instructor

| File | Use |
|---|---|
| `MP1-evaluation-tracker.xlsx` | Four sheets: the marks tracker with live totals, the rubric with full/half/zero descriptors, a 17-question ownership bank, and eight live-modification tasks |
| `evaluation-sheet.md` | Printable one-page slip per student, for when the lab machine is busy |

**Before the class:** fill columns A–E of the tracker from the submitted links,
and check each repository and deployed URL. That pre-check is what makes a
50-minute evaluation of a large class possible.

**During:** type marks only into the five yellow columns; column K totals them.
Row 8 is an example — delete it first.

The slide deck for the class is in `../../study-materials/slides/`. Project it
for the whole hour so waiting students can see the procedure and the rubric.
