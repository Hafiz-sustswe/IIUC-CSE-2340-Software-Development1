2. Specificity beats source order

The element rule is written LAST. Does it win?

No. .btn (0-1-0) beats button (0-0-1), even though button comes later in the file.

3. Specificity is not a sum

Three classes versus one id. Which wins?

Inspect me

The id wins. 1-0-0 beats 0-3-0 because the first number is compared first. It is not 1 versus 3.

4. Inline styles

An inline style versus a class. Which wins?

Inspect me — the inline style wins (1-0-0-0).

This is why inline styles are hard to override, and why you should not use them.

5. !important

Can anything beat an inline style?

Inspect me — !important beats even the inline style.

It works, which is exactly the problem: the next conflict now needs another !important, and so does the one after that.
